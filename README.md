# Mac Meshtastic Client
A project to build a chat app for desktop. This project is mostly written by Claude, with key functions in python written by me.

## Why?
There are few issues I have with the meshstatic client for the mac -- mainly it isn't as user friendly as I would like it to be. This maybe due to my relative newness to the Mesthastic protocol, or it may just be neurodivergence. Regardless, this is a good project to learn both mesh and python.

## Goals
- To create a universal app, with themes and security baked into it
- To learn additional features of Mesh and Python
- To send and recieve messages from other users/nodes
