## Why this is first

The process defines a standard of evidence — **a test that has never been shown to fail is
not evidence** — and ships no harness, deliberately. Until `C1` exists, every later claim in
this project is an assertion. Upstream already says so by name:

```
$ python3 ../turing-review/scripts/check_harness.py --run ../mac_mesh_client
H14 — 0 of 1 project(s) declare a harness (floor 1)
  none  mac_mesh_client
    no `## Stack` in any spec under docs/specs/
    no `## Harness` in docs/conventions-local.md
  FAIL — 0 declaring, below the floor of 1.
```

Both halves of that are now written — `## Stack` in the spec, `## Harness` in
`docs/conventions-local.md` — so the declaration exists and the **commands do not**. `C1`
makes the declaration true.

## The five capabilities

| | Done when |
|---|---|
| **run** | one command runs every check and exits non-zero on failure |
| **count** | one command prints the number of assertions that actually **executed** |
| **floor** | a file holding a number the count may not fall below |
| **mutate** | at least one named way to break the code, paired with the test that catches it |
| **precommit** | a hook that runs the gates **after** the last edit, not before |

## `M1` — the first mutation

**Named here, run before the register row is written.** `caught at n/m` is evidence;
*prevented by construction* is an argument, and every one of the five failures that produced
this rule upstream was an argument.

> **`M1`: replace the runtime read of `DATA_PAYLOAD_LEN` with the literal `190`.**

Caught by the byte-budget test from `C1-T3`. It is the right first mutation because it is
the mistake this project **actually made** — 190 sat in an approved intent as a stated
constraint until the constant was read out of the library — and because a test that fails on
it is a test that could not have been written by re-deriving its own expected value.

Two traps this test must avoid, both on record upstream:

- **An assertion that re-derives its expected value cannot see the path that produces the
  real one.** Read the limit where it leaves the system, not by recomputing what it ought
  to be.
- **A fixture satisfying both the right and the wrong implementation distinguishes nothing.**
  A pure-ASCII string cannot tell a byte budget from a character count. The fixture is
  multi-byte, deliberately.

radio*, and performing it costs one unplugged cable.
